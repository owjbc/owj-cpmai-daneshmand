# پروتکل برگزاری بوت‌کمپ آموزشی CPMAI — شرکت مشاوران مدیریت کسب و کار اوج

> **ویژه هلدینگ پایا سامان پارس — مؤسسه تحقیق و توسعه دانشمند (بنیاد مستضعفان انقلاب اسلامی)**  
> نسخه دیجیتال و تعاملی پروتکل: [https://owjbc.github.io/owj-cpmai-daneshmand/](https://owjbc.github.io/owj-cpmai-daneshmand/)

این مخزن شامل پروتکل اجرایی، استانداردهای فنی، چک‌لیست تعاملی سالن و کاتالوگ رسمی ۸ صفحه‌ای آماده چاپ A4 برای بوت‌کمپ آموزشی راهبری هوش مصنوعی (CPMAI) شرکت مشاوران مدیریت کسب و کار اوج ویژه هلدینگ پایا سامان پارس و مؤسسه تحقیق و توسعه دانشمند است.

## اجرای محلی

```bash
npm install --legacy-peer-deps
npm run dev
```

## ساخت خروجی نهایی

```bash
npm run build
```
