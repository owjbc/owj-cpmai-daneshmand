# پروتکل برگزاری بوت‌کمپ آموزشی CPMAI — شرکت مشاوران مدیریت کسب و کار اوج

> **ویژه طرح پتروشیمی دماوند**  
> نسخه دیجیتال و تعاملی پروتکل: [https://owjbc.github.io/owj-cpmai-protocol/](https://owjbc.github.io/owj-cpmai-protocol/)

این مخزن شامل پروتکل اجرایی، استانداردهای فنی، چک‌لیست تعاملی سالن و کاتالوگ رسمی ۸ صفحه‌ای آماده چاپ A4 برای بوت‌کمپ آموزشی راهبری هوش مصنوعی (CPMAI) شرکت مشاوران مدیریت کسب و کار اوج است.

## اجرای محلی

```bash
npm install --legacy-peer-deps
npm run dev
```

## ساخت خروجی نهایی

```bash
npm run build
```
